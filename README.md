## iOS Scriptable Widget

An interactive Scriptable widget for iOS that tracks your A-Level past paper grades and visualises your progress

## Features
* Displays current grade averages and paper breakdowns
* Reads and writes local JSON data
* Clean visual UI for iOS home screen widget

## Installation
1. Open the **Scriptable** app on your iPhone or iPad
2. Tap the `+` icon to create a new script
3. Copy the code from `grade-tracker.js` and paste it into the editor
4. Save the script, go to your iOS home screen, and add a Scriptable medium sized widget
